BSc Computer Science: Student Project:

Check out the website here: Mutable: Music & News.

The instruction was to create a blog style website entirely out of vanilla web code (e.g. HTML, CSS and JS (no frameworks))
I decided to do a South African local music news/blog app to promote and review local music under a cohesive fictitious brand/platform called “Mutable: Music & News”.

Website code, visual assets and all other content was produced by me. Wireframing and site planning was part of the project. The articles get generated from a JSON database file to make it easy to add new events and articles to the website.
