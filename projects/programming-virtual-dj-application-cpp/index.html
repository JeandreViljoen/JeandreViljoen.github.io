BSc Computer Science: Student Project:

The instruction was to build and enhance a software-based music DJ application using a GUI library.
The idea was for it to represent the functionality of a DJ desk as a software application.

Having a background in audio, this was a fun project but failed to achieve my main goal of incorporating practical DJ effects and tools. Despite not quite nailing my goals, it was still a cool and functional app in the end.

The app was coded in C++ and the GUI library used was the JUCE framework.
